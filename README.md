# 桌面领航员 astrbot_plugin_desktop_pilot

让 AstrBot 的大模型通过截图操控 Windows 电脑：看屏幕、点按钮、打字、滚动、拖拽、切换和启动程序。

专门解决高分屏笔记本上「模型算的坐标总是点歪」的问题。

## 为什么会点歪

以 2560×1600、缩放 150% 的笔记本为例：截图发给模型前会被缩小（比如缩到 1728×1080），模型报出的是缩小图上的坐标，但点击工具把它当成真实屏幕坐标，于是整体往左上角偏。很多模型服务商还会把图片再压缩一次，模型自己都不知道图被缩了多少。

## 本插件的做法

1. **元素编号优先**：通过 Windows UI Automation 读取按钮、输入框等可交互元素的真实位置，在截图上画框编号。模型只需说「点 12 号」，插件直接点击元素中心，完全不受分辨率和缩放影响。
2. **坐标自动换算**：每张返回给模型的图片都记录了它覆盖的屏幕区域和尺寸，模型给出的坐标由插件换算成物理像素，模型不需要做任何计算。
3. **千分比坐标**：默认使用 0~1000 的千分比坐标，这是 Qwen-VL、豆包、Gemini 等模型训练时使用的格式；即使服务商再次压缩图片，比例也不会变。使用 GPT、Claude 时可切换为图片像素坐标。
4. **放大镜**：游戏、画布等读不到元素的场景，模型可以先放大某个区域再精确定位，两次缩放由插件一并换算。
5. **DPI 正确**：在专用线程上启用 Per-Monitor V2 DPI 感知，截图、元素位置、鼠标坐标统一使用物理像素，多显示器、缩放比例不同的显示器都能对齐。

## 提供给模型的工具

| 工具 | 作用 |
| --- | --- |
| `desktop_screenshot` | 截图并标注元素编号，返回元素列表 |
| `desktop_zoom` | 放大查看最近一张图片中的某块区域 |
| `desktop_click` | 按编号或坐标点击（左/右/中键，单击/双击/仅移动） |
| `desktop_type` | 输入文字（支持中文，不经过输入法），可先点击目标、清空、回车 |
| `desktop_scroll` | 滚动滚轮 |
| `desktop_drag` | 拖拽 |
| `desktop_hotkey` | 按键或组合键 |
| `desktop_app` | 列出窗口、切换窗口、从开始菜单启动应用 |

## 安装与使用

1. AstrBot 必须运行在被操控的那台 Windows 电脑上，且运行在已登录的桌面会话中（不能是 Windows 服务或锁屏状态）。
2. 在 AstrBot 中安装本插件，依赖会自动安装（`uiautomation`、`mss`、`pillow`）。
3. 使用支持图片输入的模型，并确认该模型提供商的「模态」配置包含图片。
4. 对 bot 说「帮我打开记事本写一段话」之类的指令即可。

## 配置说明

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 仅管理员可用 | 开 | 只有 AstrBot 管理员和白名单用户能操控电脑 |
| 额外允许的用户 ID | 空 | 非管理员的白名单 |
| 坐标模式 | normalized | `normalized` 千分比，`pixel` 图片像素 |
| 截图最长边 | 1280 | 越大越清晰，越费 token |
| 截图格式 / JPEG 质量 | jpeg / 80 | png 无损但体积大 |
| 标注元素编号 | 开 | 关闭后只能用坐标操作 |
| 最多标注元素数 | 120 | 前台窗口优先 |
| 读取元素超时 | 3 秒 | 复杂界面只返回超时前读到的元素 |
| 默认截图显示器 | 0 | 0 前台窗口所在，-1 全部，1、2… 指定 |
| 文字输入方式 | unicode | 个别程序不认时改为 paste（剪贴板粘贴，完成后恢复剪贴板） |
| 动作后自动截图 | 关 | 开启后少一轮模型调用，但上下文增长更快 |
| 禁用的组合键 | win+l、ctrl+alt+delete | 可加入 alt+f4、win+r 等 |

## 安全提醒

能操控电脑的 bot 权限极大，等同于把鼠标键盘交给了对它说话的人。请保持「仅管理员可用」开启，不要在公开群里开放给所有人。

## 已知限制

- 以管理员权限运行的程序（任务管理器、部分安装程序）会拦截普通权限进程的模拟输入，需要 AstrBot 也以管理员身份运行才能操作。
- 锁屏、UAC 安全桌面、远程桌面断开后的会话中无法截图和操作。
- 游戏、视频播放器等自绘界面读不到元素，只能用坐标和放大镜。
